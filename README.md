Entrants sum up an ex in exactly one word; a judge model compares the words head to head and the funniest verdict takes the pool. This entry's word is **Understudy** — the ex never got the lead role; he spent the whole relationship waiting in the wings as the backup.

## Run it

```sh
python3 main.py
```

Writes the one-word verdict to `/output/entry.txt` (exactly `Understudy`, 10 characters, one word, no trailing newline).
